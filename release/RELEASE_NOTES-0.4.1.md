# 页签备注 v0.4.1 发布说明

> 前缀规则字段补全版本。状态：已完成语法、单元、真实浏览器侧栏交互与安装包验收；日期：2026-08-18。

## 修复与增强

- 网址前缀规则现在可以设置默认分类和默认颜色。
- 匹配页面在没有单页备注时，会继承规则的短标题、分类、颜色和详细备注。
- 单页备注仍完整优先；删除单页覆盖后恢复全部前缀默认字段。
- 旧版前缀规则保持兼容：未设置分类时为空，未设置颜色时使用蓝色。
- 原有 Tab 右键“修改页签备注”入口已做回归验证并保留。
- 没有新增 Chrome 权限。

## 验收结果

- 前缀规则的分类和颜色可保存、重新读取并显示在规则列表中。
- 匹配网页能继承短标题、分类、颜色和详细备注。
- 单页备注可完整覆盖规则；删除单页备注后恢复全部规则默认字段。
- 100 标签页模拟中，原单页保存仍为存储读取 1 次、写入 1 次、标签查询增量 0 次。
- 运行时代码语法、共享逻辑、后台定向刷新、Tab 右键菜单与压缩包完整性检查全部通过。
