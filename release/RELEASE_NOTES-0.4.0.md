# 页签备注 v0.4.0 发布说明

> 网址前缀默认备注版本。状态：已完成语法、单元、后台定向刷新、100 标签页交互与安装包验收；日期：2026-08-18。

## 新功能

- 新增“网址前缀规则”，可为一组网页设置默认标签短标题和默认详细备注。
- 匹配页面在没有单独备注时自动使用前缀默认值。
- 单页备注完整优先，短标题、详细备注、分类、颜色和网页备注卡仍可逐页修改。
- 删除单页覆盖后自动恢复前缀默认值。
- 支持多条重叠规则，最长、最具体的前缀优先。
- 修改规则时只刷新匹配旧前缀或新前缀的页面。

## 兼容性

- 沿用原有 `notesByUrl` 逐页备注数据，不迁移、不覆盖旧备注。
- 前缀规则单独保存在本机 `prefixRules` 存储项中。
- 没有新增 Chrome 权限。

## 验收结果

- 新建规则后，100 个匹配页面会使用默认短标题和默认详细备注。
- 保存单页备注后完整覆盖默认值；删除单页备注后恢复前缀默认值。
- 修改前缀规则只刷新匹配旧前缀或新前缀的标签页。
- 100 标签页模拟中，原单页保存仍为存储读取 1 次、写入 1 次、标签查询增量 0 次。
- 运行时代码语法、共享逻辑测试、后台缓存测试和压缩包完整性检查全部通过。
