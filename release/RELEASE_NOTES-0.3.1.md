# 页签备注 v0.3.1 发布说明

> 大量标签页场景下的交互性能优化版本。状态：已完成语法、单元和 100 标签页模拟验收；日期：2026-08-17。

## 更新内容

- 保存或删除备注后只刷新相同网址的标签页，不再逐个刷新全部已打开标签。
- 后台缓存备注数据，标签切换和标题更新不再重复读取本地存储。
- 侧边栏复用已加载的标签数据，合并连续更新并使用批量 DOM 插入。
- 保存时立即显示状态并更新列表，移除重复的全量重新加载。
- 右键切换目标标签后直接更新当前编辑器并聚焦短标题输入框。

## 验收结果

- 模拟 100 个标签页：修改一个网址的备注只向对应 1 个标签发送状态更新。
- 模拟 100 个标签页：保存期间标签查询次数增量为 0，存储读取和写入各 1 次。
- 模拟环境中从提交到显示“已保存”的面板内部耗时约 0.4 ms，不包含 Chrome 实际磁盘写入时间。
- `shared.js` 与 `background.js` 回归测试通过，全部运行时代码语法检查通过。
