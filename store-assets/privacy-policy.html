页签备注隐私政策

适用于“页签备注（Tab Notes）”Chrome 扩展 · 生效日期：2026-08-17

1. 扩展的用途

页签备注用于给网页标签添加短标题、分类、颜色和详细备注，并通过侧边栏搜索和切换标签页。

2. 处理的数据

为了提供上述功能，扩展会在用户设备本地处理当前及已打开网页的网址、标题和网站图标地址，以及用户主动输入的短标题、分类、详细备注、备注颜色、网页备注卡开关和创建/更新时间。

3. 数据的使用方式

这些数据仅用于将备注摘要显示在对应网页标题中；在扩展侧边栏中展示、搜索和切换网页；在用户选择时显示网页内备注卡；以及让备注在 Chrome 重启后继续保留。

4. 本地存储与传输

扩展使用 chrome.storage.local 将备注保存在当前 Chrome 用户配置中。扩展没有服务器、账号系统、分析服务、广告 SDK 或远程代码，不会把网址、网页标题、备注或其他用户数据发送给开发者或任何第三方。

5. 数据共享和出售

扩展不会出售、出租、共享或以广告目的使用用户数据，也不会允许开发者或其他人员读取用户备注。

6. 数据保留与删除

数据会一直保存在本地，直到用户在扩展中删除对应备注、清除扩展存储数据或卸载扩展。用户可以随时在侧边栏中删除单条备注。

7. 权限说明

  • storage：在本地保存用户备注。
  • tabs：读取网页标题和网址，并切换用户选择的标签页。
  • sidePanel：显示备注编辑和网页管理界面。
  • scripting：让安装前已打开的普通网页也能立即显示标题备注。
  • contextMenus：在标签页右键菜单中提供“修改页签备注”。
  • http://*/*、https://*/*：在普通网页中更新文档标题，并在用户开启时显示备注卡。

扩展不能在 Chrome 内部页面等受保护页面中注入脚本。

8. Chrome Web Store Limited Use

本扩展对从 Chrome API 获得的信息的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。数据只用于提供用户可见的页签备注功能。

9. 政策变更

如果数据处理方式发生变化，开发者会更新本政策，并在扩展界面和商店页面中进行清晰披露。
