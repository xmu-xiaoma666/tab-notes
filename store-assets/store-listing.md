# Chrome Web Store 发布文案

## 基本信息

- 名称：页签备注 - Tab Notes
- 类别：生产力工具
- 默认语言：简体中文
- 简短说明（不超过 132 字）：为网页标签添加短标题、颜色、分类与本地备注，支持 Tab 右键编辑和侧栏搜索；所有数据仅保存在本机。

## 详细说明

标签页太多、标题又几乎一样？页签备注可以给每个网页添加容易识别的短标题、颜色、分类和详细备注。

主要功能：

- 在标签标题最前面显示短标题和备注摘要；
- 右键任意标签页，选择“修改页签备注”；
- 按网址前缀设置默认短标题、分类、颜色和详细备注，同时保留逐页修改能力；
- 通过 Chrome 侧边栏编辑、搜索和切换网页；
- 按完整网址保存，支持带 `#` 的单页应用路由；
- 可选网页右上角可折叠备注卡；
- 已关闭网页的备注仍会保留，可从侧边栏重新打开；
- 支持明暗主题和快捷键。

隐私说明：扩展没有服务器、账号、广告、分析 SDK 或远程代码。网址、网页标题和用户备注仅在本机使用 `chrome.storage.local` 保存，不会发送给开发者或第三方。

## Single purpose

让用户为网页标签添加本地备注，并通过备注快速识别、搜索和切换标签页。

## 权限用途说明

- `storage`：将用户创建的备注保存在本地。
- `tabs`：读取标签页的网址和标题以关联备注，并切换用户选择的标签页。
- `sidePanel`：承载备注编辑、搜索和网页列表界面。
- `scripting`：在安装前已经打开的普通网页中注入标题备注功能。
- `contextMenus`：在 Tab 右键菜单中提供“修改页签备注”。
- Host permissions `http://*/*`, `https://*/*`：在普通网页中更新文档标题，并在用户主动开启时显示备注卡。

## Remote code

No. 扩展不加载或执行任何远程代码。

## 数据披露建议

- Web history / browsing activity：是，仅在本机处理网址和标签标题，以关联和展示备注；不传输。
- User-generated content：是，仅在本机保存用户输入的备注；不传输。
- Website content：否。扩展不读取网页正文，只读取浏览器提供的标签标题、网址和网站图标地址。
- Authentication / financial / health / personal communications：否。
- Limited Use certification：全部勾选并确认遵守。
